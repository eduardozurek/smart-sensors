# Smart Sensors

## Descripción

Este repositorio forma parte del taller **Smart Sensors**, que se desarrollará en el marco del evento IEEE de la **Universidad del Norte**, Barranquilla, Colombia, el **21 de octubre de 2026**.

## Dataset

Para el desarrollo de esta actividad utilizaremos el conjunto de datos:

**WISDM Smartphone and Smartwatch Activity and Biometrics Dataset**

El dataset está disponible en el repositorio de aprendizaje automático de la Universidad de California, Irvine (UCI).

**Enlace:** [WISDM Dataset - UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/507/wisdm+smartphone+and+smartwatch+activity+and+biometrics+dataset)

## Objetivos del taller

- Introducir el uso de sensores de dispositivos inteligentes.
- Explorar datos provenientes de smartphones y smartwatches.
- Analizar señales relacionadas con actividades humanas.
- Aplicar técnicas de análisis de datos y aprendizaje automático.
