# Introducción a Smart Sensors

## 1. ¿Qué es un sensor?

Un sensor es un dispositivo que permite detectar o medir
una magnitud física y convertirla en una señal utilizable.

## 2. ¿Qué es un Smart Sensor?

Un Smart Sensor combina capacidades de medición,
procesamiento y comunicación.

## 3. Aplicaciones

- Monitoreo de actividades humanas.
- Sistemas de salud.
- Internet de las Cosas (IoT).
- Automatización industrial.

## 4. Sensores utilizados en el taller

Durante el taller IBERSENSOR 2026 utilizaremos:

- Acelerómetro.
- Giroscopio.
